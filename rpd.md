# Рабочий Проектный Документ (RPD) - DataSciBench

Этот документ предназначен для быстрого погружения ИИ-агента в контекст проекта при последующих сессиях.

## Суть проекта
**DataSciBench** — это бенчмарк для языковых моделей (LLM) и агентов, сфокусированный на решении задач по Data Science (построение предиктивных моделей, анализ данных, обучение нейросетей и т.д.). В его основе лежит сильно кастомизированная и "облегченная" версия фреймворка **MetaGPT**.

## Структура директорий
- `/metagpt` — ядро фреймворка MetaGPT, переведенное из внешнего пакета в локальный модуль. Из него удалены все неиспользуемые части (сильно "обрезан"). Импортируется напрямую как `import metagpt`.
- `/src` — исходный код логики бенчмарка (схемы, утилиты, эвалюаторы, VLM-сервисы).
- `/role` — содержит кастомные роли агентов, в частности `sci_data_interpreter` (Science Data Interpreter), который адаптирован под задачи бенчмарка.
- `/experiments` — скрипты запуска экспериментов. Основная точка входа — `run_examples.py`.
- `/evaluations` — скрипты для проверки результатов выполнения задач (успешность, корректность кода).
- `/evaluation_results` — хранилище сырых логов и финальных метрик (Pass@1, Completion Rate).
- `/benchmark_generator` — модуль для автоматической генерации новых задач на основе произвольного кода.
- `/scripts` — вспомогательные bash и python скрипты для автоматизации оценки моделей (`evaluate_model.sh`, ротация ключей и т.д.).
- `/data` — наборы данных для задач (25 human, 20 csv_excel, 10 dl). Включает промпты и входные файлы.
- `config2.yaml` — основной файл конфигурации (LLM API ключи, эндпоинты, параметры моделей).

## Основные команды запуска (из корня DataSciBench)
**Запуск экспериментов (генерация решений):**
```bash
python -m experiments.run_examples --max_runs 3
```
*По умолчанию используется 3 запуска на задачу (ранее было 10).*

**Проверка сгенерированных результатов (Eval):**
```bash
python -m experiments.evaluate --task_id all --model_id <имя_модели>
```

**Расчет финальных метрик:**
```bash
python -m evaluation_results.calculate_final_metric
```

**Полный цикл оценки одной модели:**
```bash
./scripts/evaluate_model.sh <имя_модели>
```

## Ключевые особенности и механизмы защиты
- **Repetition Detection**: Встроены механизмы детекции зацикливания генерации LLM. При обнаружении повторов генерация принудительно обрывается (`RepetitionError`).
- **Early Stopping**: Агенты ограничены максимальным числом попыток на одну подзадачу (обычно 5), чтобы избежать бесконечных циклов "ошибка-исправление".
- **API Key Rotation**: Реализована автоматическая ротация ключей из списка в конфиге для обхода лимитов (round-robin).
- **Environment Diagnostics**: При запуске логируется текущая директория и состав файлов для отладки путей.
- **Forced Streaming**: Все запросы к LLM используют стриминг для работы детектора циклов в реальном времени.
